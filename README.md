# Java Mini Application

A Maven Spring Boot application using MySQL.

Set `DB_URL`, `DB_USERNAME` and `DB_PASSWORD` in the environment, then run `./mvnw spring-boot:run` (`mvnw.cmd spring-boot:run` on Windows). The default port is 8088 and the default local database URL is `jdbc:mysql://localhost:3306/javamini`.

A Java server and MySQL are required; GitHub Pages cannot run this application. IDE metadata, build output and local credentials are excluded from the repository.
